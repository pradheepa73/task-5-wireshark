## Filter Analysis

### TCP SYN Filter (`tcp.flags.syn == 1 && tcp.flags.ack == 0`)
- **Observation:** 159 SYN packets identified
- **IPv6 traffic:** 128 packets (80.5%)
- **IPv4 traffic:** 31 packets (19.5%)
- **Purpose:** Detect new TCP connection attempts

### Protocol Breakdown
- **Ethernet:** All frames encapsulated with MAC addressing
- **IPv6:** Modern addressing — dominant protocol in this capture
- **IPv4:** Legacy addressing — still present for compatibility
- **TCP:** Reliable transport carrying all connection attempts

## Interview Q&A

**1. What is Wireshark used for?**
Network protocol analyzer for troubleshooting, security investigations, and protocol learning.

**2. What is a packet?**
A formatted unit of data with a header (routing info) and payload (actual data).

**3. How to filter packets in Wireshark?**
Type display filters in the top bar, e.g., `dns`, `tcp.port == 443`, `ip.addr == 8.8.8.8`.

**4. Difference between TCP and UDP?**
TCP is connection-oriented, reliable, ordered. UDP is connectionless, unreliable, faster.

**5. What is a DNS query packet?**
A UDP packet sent to port 53 asking to resolve a domain name to an IP address.

**6. How can packet capture help in troubleshooting?**
Identify dropped packets, retransmissions, latency, misconfigured DNS/TLS.

**7. What is a protocol?**
A set of rules defining how data is formatted and exchanged (TCP, UDP, HTTP, DNS).

**8. Can Wireshark decrypt encrypted traffic?**
Only with session keys (SSLKEYLOGFILE) or private keys for TLS; WPA2 PSK for Wi-Fi. SSH is not decryptable.

## Lessons Learned

1. DNS resolves before every connection - pattern is DNS -> TCP SYN -> TLS handshake.
2. Modern web is encrypted - TLS dominates web traffic.
3. Filters turn chaos into clarity - 10,000 packets become 50 with the right filter.
4. ICMP is fundamental - ping works at Layer 3, no ports involved.
5. Protocol hierarchy is the fastest overview - one click shows traffic composition.
